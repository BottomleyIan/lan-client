Help

Use the command palette to control playback or add a quick note without leaving your current page.

Command palette

  • Open: Press Ctrl + Shift + P.
  • Close: Press Esc.

Commands

  • play

    Start playback.

  • pause

    Pause playback.

  • next

    Skip to the next track.

  • add

    Open the quick note editor.

  • today

    Jump to today’s notes page.

  • notes {tag}

    Open notes filtered by a tag.

  • tasks

    Open the tasks board.

  • tasks {tag}

    Open tasks filtered by a tag.

  • help

    Open this help page.

In add mode, press Enter to submit a note. Use Shift + Enter for a new line.
